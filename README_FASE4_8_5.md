# Proyecto Águila — Fase 4.8.5

## Cambios

- Todas las citas en lunes generan el recordatorio el sábado anterior.
- Pasaporte Mexicano usa el nombre “Cita en Relaciones Exteriores”.
- El seguimiento para Visa Americana se crea automáticamente el mismo día de la cita de pasaporte a las 15:30.
- Agenda optimizada para computadora con columnas: Atrasadas, Hoy, Mañana y Próximas.
- Los trámites concluidos salen automáticamente de Operación Activa.
- Todos los usuarios siguen viendo la operación general.
- Cada trámite puede asignarse a un usuario concreto.
- Se puede indicar prioridad y fecha prioritaria de atención.
- La asignación prioritaria crea una tarea urgente en Agenda para el usuario responsable.

## Instalación

1. Ejecuta `supabase/fase4_8_5_asignacion_prioridad.sql`.
2. Sube el contenido interior de esta carpeta a GitHub.
3. Espera que Vercel muestre Ready.
4. Prueba con un trámite ficticio asignado a un usuario y una fecha cercana.
