# Proyecto Águila — Fase 5.4.3 · Prospectos 2.0

## Incluye

- Expediente individual de cada prospecto.
- Bitácora de anotaciones y resultados.
- Próximo seguimiento configurable.
- Agenda comercial con calendario mensual.
- Vistas rápidas: atrasados, hoy, mañana, próximos, sin fecha y sin seguimiento.
- Alerta en la bandeja inteligente después de dos días sin avance.
- Respeto de una fecha futura ya programada: no se alerta antes de esa fecha.
- Accesos directos a llamada, WhatsApp, conversión y cierre como perdido.

## Instalación

1. Ejecuta `supabase/fase5_4_3_prospectos_2_0.sql` en Supabase.
2. Sube el contenido interior de esta carpeta al repositorio.
3. Espera que Vercel muestre `Ready`.
4. Registra prospectos de prueba y valida el calendario, anotaciones y alertas.
